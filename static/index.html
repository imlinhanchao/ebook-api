ebook-api 是纯 Go 标准库零依赖打造的电子书搜索与流式下载后端，提供 AES-256-GCM 无状态加密令牌（ebk1.*）、流式透传与 CDN ETag 缓存。轻度使用可直接采用 Echo 客户端内置的免部署声明式书源；需要强风控中转、加密共享凭据或 CDN 缓存省配额时，按下方步骤即可上线本服务。

服务架构 · Overview

轻量无库、安全的后端中转能力

单文件即可在路由器、NAS、桌面 PC 或轻量云服务器长期稳定运行，安全托管上游会话并支持多书源并发调度。

零依赖单文件

纯 Go 1.24+ 标准库构建，无需数据库或外部运行库，任意工作目录启动内置静态资源自动兜底。

无状态加密令牌

采用 AES-256-GCM（AAD 绑定书源 ID）将账号凭据封装为 ebk1.* 令牌，请求头与代理日志绝不暴露明文。

流式透传与 CDN 缓存

大文件不落盘直出透传，确定性下载路径自带长期 Cache-Control 与 ETag，跨账号共享缓存省额度。

多书源镜像调度

插件化 Provider 接口解耦，支持单源与并发聚合搜索，内置镜像健康缓存与风控自动故障切换。

适合 Docker 宿主机与群晖 / 威联通 / 飞牛等 NAS：默认已绑定 0.0.0.0:8091。务必挂载 ./data:/app/data，保证重装或升级容器后已生成的 secret.key 不丢失。

1. 推荐挂载持久化卷的 docker-compose.yml（或 override） 
services:
  ebook-api:
    build: .
    container_name: ebook-api
    restart: unless-stopped
    ports:
      - "8091:8091"
    env_file:
      - path: .env
        required: false
    environment:
      EBOOK_ADDR: 0.0.0.0:8091
    volumes:
      - ./data:/app/data

git clone https://github.com/imlinhanchao/ebook-api.git
cd ebook-api
cp .env.example .env

# 按需在下方「生成 .env 配置」填入参数后启动

docker compose logs -f ebook-api

# 日常升级命令
git pull && docker compose up -d --build

适合 Linux 服务器或迷你主机后台常驻与崩溃自启：按模板把二进制放至 /opt/ebook-api/bin/ebook-api 并注册用户级 systemd 服务。

1. 部署目录与启用后台服务 
mkdir -p /opt/ebook-api/bin /opt/ebook-api/data /opt/ebook-api/.tmp ~/.config/systemd/user
# 将解压后的 ebook-api 二进制放入 /opt/ebook-api/bin/ebook-api，.env 与 static/ 放入 /opt/ebook-api/

Step 2 · 生成配置

交互式生成 .env 配置文件

根据部署场景勾选选项、一键生成随机密钥，直接复制到服务根目录的 .env 文件即可启动。

访问方式（决定 EBOOK_ADDR）
生成的 .env 内容（纯浏览器本地生成，不上传） 
EBOOK_ADDR=0.0.0.0:8091
EBOOK_DATA_DIR=data
# 留空则首次启动自动生成并持久化到 data/secret.key
# EBOOK_SECRET=
EBOOK_ALLOW_PLAIN_CRED_HEADERS=false
ZLIB_DOMAINS=https://z-lib.gd,https://z-lib.gl,https://z-library.ec,https://zlib.bz
  • EBOOK_ADDR：家里电脑/NAS 让手机直连选 0.0.0.0；有 Caddy/Nginx 挡在前面选 127.0.0.1 避免裸端口暴露公网。
  • EBOOK_API_KEY：公网部署强烈建议生成并填写，Echo 连接服务时同步输入此 Key 即可鉴权。
  • EBOOK_SECRET：固定 64 位 Hex 主密钥后，容器重建、迁移或更换机器时，Echo 已保存的 ebk1.* 书源令牌依然有效。
Step 3 · 公网 HTTPS（可选）

Caddy / Nginx 反向代理配置

需要在外网随时搜书时，建议将 ebook-api 仅监听 127.0.0.1:8091 并配置 HTTPS 反向代理。下载接口为流式大文件透传，请关闭代理缓冲。

Caddyfile（自动签发 HTTPS 证书，推荐） 
ebook.example.com {
    reverse_proxy 127.0.0.1:8091 {
        # 关闭输出缓冲，立即向客户端透传图书下载流
        flush_interval -1
    }
}
Nginx Server Block（关闭缓冲并延长下载超时） 
server {
    listen 443 ssl http2;
    server_name ebook.example.com;

    location / {
        proxy_pass http://127.0.0.1:8091;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_buffering off;
        proxy_read_timeout 300s;
    }
}

CDN 回源省配额提示：下载路径 /v1/providers/*/books/*/download 跨账号固定且自带长期 Cache-Control 与 ETag；在 .env 勾选 EBOOK_PUBLIC_DOWNLOAD=true 与服务端默认凭据并让 CDN 按纯 URL 缓存，命中后不再消耗上游每日下载额度。

Step 4 · 客户端接入

三步接入 Echo 客户端

服务上线后，在 Echo 手机或桌面端添加为 ebook-api 书源即可搜书与流式下载，与其他声明式书源在同一搜索切换器中无缝共存。

当前服务接入地址 http://<你的设备IP>:8091
01

确认服务在线

通过浏览器或 curl 访问上方地址的 /health 路径，返回 "status": "ok" 与已注册书源列表，即表示网络端口与进程均已就绪。

02

在 Echo 书源管理添加

在首次引导第 1 步，或「我的 → 书源管理 → 右上角 + → 切换至 ebook-api 标签」输入上方服务地址、可选 API Key 与远端书源 ID（默认 zlib），测试连接通过后保存。

03

登录书源开始搜书

在「书源管理」进入刚添加的书源详情页，选择可用镜像并完成账密或 Cookie 登录即可在搜索页切换使用；也可随时启用内置公版源，或在右上角菜单「全部停用」仅用本地导入。

常见卡点

部署常见排错

90% 的部署问题集中在监听地址、防火墙放行与容器密钥持久化，按下方条目逐项核对即可快速解决。

1. 手机连不上电脑 / NAS 的 8091 端口？
  • 检查 .env 中是否为 EBOOK_ADDR=0.0.0.0:8091（默认的 127.0.0.1:8091 仅允许本机访问）。
  • 确认宿主机防火墙（Linux ufw / firewalld、Windows 专用网络防火墙、云服务器安全组）已放行 8091 端口，且手机与主机处于同一局域网网段。
2. 容器重建或迁移后，Echo 提示书源会话失效？
  • 每次重新生成容器且未挂载 /app/data 时，服务端会生成新的随机密钥，导致客户端本地保存的 ebk1.* 加密令牌无法解封。
  • 请在 docker-compose.yml 挂载 ./data:/app/data，或在 .env 显式固定 32 字节的 EBOOK_SECRET 后在 Echo「书源管理 → 书源详情」重新保存一次即可一劳永逸。
3. 经过反代后下载大体积电子书超时或卡顿？
  • 确保反代未启用默认响应缓冲并放宽上游读取超时：Nginx 务必配置 proxy_buffering off; 与 proxy_read_timeout 300s;，Caddy 配置 flush_interval -1。
4. 搜索超时或提示镜像被拦截（503）？
  • 这通常说明当前选中的 Z-Library 镜像与部署主机之间连通受阻或触发站点风控；请在 Echo「我的 → 书源管理」进入该书源详情页测试并切换其他可用镜像，或在服务端 .env 调整 ZLIB_DOMAINS 顺位。
